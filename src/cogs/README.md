# ⚙ Commands & Functions

Takohachi の機能(Cog)一覧です。コマンドはすべてスラッシュコマンドで、特記がない限り誰でも実行できます。

## 📌 読み込みルール

`src/main.py` で次のように読み込まれます。

- **常に読み込まれる Cog**: コマンド系の Cog。
- **本番のみ読み込まれる Cog**: 環境変数 `PREFIX` が `!!` のときだけ読み込まれます。
  開発用 Bot と本番 Bot での二重反応・二重投稿を防ぐためです。
  - `autodelete.py` / `card_count.py` / `save_image.py` / `vc_role.py` / `vcwhite.py` / `wt_task.py` / `vl_rank_task.py`
- **無効化中**: `happy_new_year.py`(`main.py` でコメントアウトされています)。

## 💬 スラッシュコマンド

### addssl.py

`/addssl {URL}`

- {URL}の情報を指定のスプレッドシートに登録します。
- このスプレッドシートの内容は[SSL Checker](https://github.com/pistachiostudio/main/blob/main/docs/sslchecker.md)に使われます。

### bath.py

`/bath`

- ニックネームの先頭に🛀絵文字をつけます。
- 🛀がついた状態で同じコマンドを打つと外します。

### card_list.py

`/card`

- スプレッドシートに記録されたユーザーごとの警告カードリアクションの上位5名を返します。

### currency.py

pisという架空の通貨機能一式です。データは SQLite(`/data/takohachi.db`)に保存されます。

`/getbonus`

- 1度限りの初期軍資金(3,000pis)をもらえます。

`/wallet {@mention}`

- 指定したユーザーの所持金を確認できます。
- 指定しない場合は自分の所持金が確認できます。

`/pay {amount} {@mention}`

- 指定したユーザーに指定した金額を送金できます。

`/rich`

- お金持ちランキングを表示します。

`/resetcurrency` 🔒

- DBのテーブルをまっさらにします。

`/givebonus {@mention}` 🔒

- 指定したユーザーに初期軍資金を無理やり与えます。

`/setmoney {amount} {bonus_flag} {@mention}` 🔒

- 指定したユーザーに指定した金額を設定します。
- bonus_flag 0 or 1 でボーナスを受け取ったかどうかの設定も可能です。
  - 0: ボーナスを受け取っていない
  - 1: ボーナスを受け取っている

🔒 = サーバー管理者のみ実行可能。

> `/shop` `/buy` は検討中のため、コード上ではコメントアウトされています。

### happy_new_year.py (無効化中)

`/hny`

- おみくじ機能です。
- 年始のみ動かしています(通常は `main.py` でコメントアウト)。

### marimo.py

`/mt`

- アメリカ東海岸の現在時刻を返します。

### message_count.py

`/count`

- コマンドを打ち込んだチャンネルの現在のメッセージ数を返します。

`/countall`

- 指定した複数チャンネルの現在の合計メッセージ数を返します。

### ping.py

`/ping`

- Botの応答速度を返します。

### purge.py

`/purge {amount}` 🔒

- コマンドを打ち込んだチャンネルのメッセージを指定した数だけ一気に削除します。

### spotify.py

`/spotify {search_type} {keyword}`

- SpotifyのAPIで曲・アーティスト・アルバムを検索し、結果を返します。
- 曲情報にはフロントには公開されていない細かい情報(Popularityなど)が含まれます。
- Spotify が2024年11月に Audio Features API の一般開放を終了したため、BPM・キーなどの分析情報は取得できません。

### text_channel.py

`/top`

- コマンドを打ったチャンネルの先頭メッセージまでジャンプできるボタンを表示させます。

### trigger.py

`/dic {keyword}`

- ユーザーが気楽にカスタムレスポンスを登録するために作った機能です。
- データベースとして使用する指定のスプレッドシートから{keyword}を検索し、結果を返します。
- `keyword` は登録済みの trigger をオートコンプリートで候補表示します(最大25件)。

### what_today.py

`/wt`

- 今日は何の日かWikipediaから取得して返します。

## 🤖 自動で動く機能

### autodelete.py 🏭

- チャンネルと時間を指定し、その時間が経過したメッセージを削除していきます。ピン留めされたメッセージは削除しません。
- 10分に1回タスクを回しています。
- 1チャンネルで失敗しても他のチャンネルの処理は続行します(Discord側の一時的なエラーでタスク全体が止まらないようにしています)。

### card_count.py 🏭

- 警告カード系の絵文字でリアクションがあると、スプレッドシートにユーザー名などを保存します。
- これは特に悪い意味では使われておらず、いい意味で使われています。
- 集計結果は `/card` で確認できます。

### gakigo.py

- サーバー内の絵文字のみの投稿をすると、決まったレスポンスをします。
- 一人のユーザーが切望してきたために作った機能です。

### save_image.py 🏭

- 指定した絵文字で画像やファイルが添付されたチャットにリアクションすると、指定したGoogle Driveにそのファイルを保存します。

### vc_role.py 🏭

- 指定したVCに入っているときだけ指定したロールを付与します。
- VCから出たら該当のロールを外します。
- VCにいる間だけ表示されるチャンネルなどのために使用しています。

### vcwhite.py 🏭

- 誰もいないVCに最初の人が入ったときだけ、指定したチャンネルにテキストで通知を送ります。

### vl_rank_task.py 🏭

- 毎朝7時台にDBに登録したユーザーのRiotのPUUIDからVALORANTのランクを取得し、前日との差分をお知らせします。
- 前日誰もプレイしていない日は、専用のメッセージをランダムで投稿します。
- 起動時に `valorant_api.py` で現在のシーズン(Act)情報を更新します。
- 10分に1回タスクを回しています。

### wt_task.py 🏭

- 毎朝7時台に指定したチャンネルに投稿されます。
- 今日は何の日か、東京・山形の天気、Geminiによる雑学(TypeSafeで事実誤認などを検証し、問題があれば最大3回まで作り直します)、為替・株価などの市場データ(USD/JPY、日経225、S&P500、NASDAQ など)を投稿します。
- 株価取得は yfinance のレート制限に備えてリトライします。
- 10分に1回タスクを回しています。

🏭 = 本番のみ(`PREFIX=!!`)で読み込まれます。

## 🧩 共通ロジック(コマンドなし)

### valorant_api.py

- スラッシュコマンドは持たず、VALORANTの現在のシーズン(Act)情報を取得・保持する共有ロジックのみを提供します。
- HenrikDev API の `v1/content` で現在有効なActを特定し、シーズンIDと表示用テキスト(例: `V26 // Act 5`)を更新します。
- `vl_rank_task.py` から利用されています。
- 環境変数 `VALORANT_TOKEN` が必要です。
